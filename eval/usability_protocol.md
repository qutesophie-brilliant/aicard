# 가설 2·3 검증 프로토콜 — 소비자 사용성 전후 비교

성과보고서의 '사회문제 해결 기여도'를 수치로 채우기 위한 최소 실험이다. 한 사람당 15분.

## 참여자
- 일반 소비자 5명 이상 (가설 2)
- 60대 이상 2~3명 (가설 3, 쉬운 말 모드)
- 참여 동의서 1장. 이름 대신 번호(P1, P2…)로 기록. 녹음·녹화 없이 관찰 기록만.

## 과제 (한 제품당 5문항, 두 제품 중 하나를 무작위 배정)
참여자에게 **원본 상세페이지**(출력물 또는 화면)를 먼저 주고 아래 5개를 찾게 한다. 각 문항 90초 제한.
그 다음 같은 제품의 **AI 정보카드**로 같은 5개를 다시 찾게 한다. 순서 효과를 줄이기 위해 절반은 카드를 먼저 본다.

| # | 질문 | 카드에서의 위치 |
|---|---|---|
| 1 | 이 제품이 'AI'라고 적은 기능은 몇 가지인가요? | 머리 숫자 |
| 2 | 그 가운데 설명서에 근거가 있는 기능은 몇 가지인가요? | 머리 숫자·■◪ 표시 |
| 3 | AI 기능이 잘 안 될 수 있는 상황이 적혀 있나요? 있다면 하나만 말해 주세요. | 작동 조건·한계 |
| 4 | AI 기능을 끌 수 있나요? | 기능 해제와 대체모드 |
| 5 | 문제가 생기면 어디로 연락하나요? | 피해구제 |

## 기록표 (참여자 1명 = 1행)

| 참여자 | 연령대 | 자료 | 정답 수(5개 중) | 걸린 시간(초) | 포기한 문항 | 쉬운 말 사용 | 한 줄 소감 |
|---|---|---|---|---|---|---|---|
| P1 | 30대 | 원본 | | | | 아니오 | |
| P1 | 30대 | 카드 | | | | 아니오 | |

## 보고 지표
- 핵심정보 발견율: 카드 vs 원본 (5개 중 평균 정답 수)
- 소요 시간: 카드 vs 원본 (평균 초)
- 60대 이상 쉬운 말 모드에서 4개 이상 찾은 비율 (목표: 전원)
- 참여자 소감 중 '자료 부족' 표시를 '나쁜 제품'으로 오해한 사례 수 (목표 0, 있으면 문구 수정)

## 주의
- 참여자에게 어느 제품이 좋은지 묻지 않는다. 묻는 것은 '정보를 찾았는가'뿐이다.
- 결과를 보고서에 쓸 때 참여자 수(n)를 반드시 함께 적는다.
