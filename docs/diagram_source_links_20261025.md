# 짧은 도식의 설명 연결 보완

## 문제와 수정

- 업로드 도식에서 ‘인공지능세탁 코스’라는 제목과 그 아래 세탁 시간·헹굼 횟수 설명이 별개 문구로 추출되어, 관련 설명이 없는 것처럼 보였다.
- 같은 이미지 또는 PDF 페이지 안에서 제목 바로 아래의 입력·동작·출력 설명을 찾아 원문 인용으로 연결한다. 새 설명 문장을 생성하지 않는다.
- 설명 조각을 별도 AI 문구로 중복 표시하지 않는다. 다른 이미지·페이지·기능, 각주, 일반 홍보 문구를 제목의 설명으로 가져오지 않는다.
- 제목과 설명 사이의 원본 줄바꿈·경계를 대조하며, 연결한 인용은 OCR로 읽은 해당 자료의 문자열 안에 있어야 한다.
- 정식 카드 생성과 기존 연구 판정 경로는 변경하지 않는다. 보완 대상은 소비자 업로드 자동 분석이다.

## 확인

- 기존 132개와 새 경계 사례 11개를 포함한 회귀시험 143개 통과.
- 실제 제조사 도식의 JPG·PNG·이미지형 PDF를 로컬 multipart 업로드에 넣고 Windows 한국어 OCR로 직접 읽었다. OCR 결과를 대체한 모의 입력이 아니다.
- 동일 OCR 입력 대조: 기존 경로는 문구 2개·연결 설명 0건, 보완 경로는 제목 1개·도식 설명 1건이다. 해당 도식에 대한 개발 사례 비교이며 새로운 정확도 수치가 아니다.
- 로컬 PDF OCR에는 ‘횟수’를 ‘횃수’로 읽은 문자 오인이 있었다. 연결 로직이 문장을 생성하거나 누락된 수치를 추정한 것은 아니며, 원문 대조는 계속 필요하다.
- 운영 서버의 AI OCR은 로컬 Windows OCR과 다른 경로이므로 배포 후 동일 파일을 다시 확인한다.

## 보존

저장 카드·승인 이력·기존 연구 수치·고정 검증자료 65개·예측·영상·음성·자막·PPT는 변경하지 않는다.
