# 실제 시스템 보완 및 심사 항목별 점검

기준: 공고문 2·5쪽. 항목별 배점·만점 기준은 공개되어 있지 않아 임의 점수를 산정하지 않는다.

## 이번 수정

1. 정식 카드 연결 시 상품 식별 쿼리(goodsNo, modelId, itemId, vendorItemId 등)를 보존한다. 모델명 부분 일치로 다른 도메인·다른 모델에 연결하지 않는다. 동일 주소가 여러 제품에 등록돼 있으면 자동으로 한 제품을 선택하지 않는다.
2. 소비자 JPG·PNG와 스캔 PDF는 이미지 번호가 확인되는 OCR 경로를 사용한다. 이미 읽은 글자는 유지하고, 미확인 이미지에 한해 제한된 재시도·서버 OCR 복구를 수행한다. 읽은 범위와 미확인 범위를 구분한다. 정식 카드 생성의 기존 OCR 기본 경로는 변경하지 않는다.
3. 자동 분석의 설명·조건 인용문에서 입력 자료의 주소를 열 수 있게 한다. 주소가 없는 업로드·붙여넣기에는 출처 주소를 만들어 표시하지 않는다.

## 검증

- 기존 116개 시험 통과를 재확인한 뒤, 별도 개발용 상품·문구와 모의 AI 응답으로 문제를 재현했다.
- 수정 후 전체 132개 회귀시험이 통과했다. 새로운 독립 정확도 측정이 아니다.
- JPG·PNG 이미지의 디코딩, 스캔 PDF 페이지 순서, AI 응답 누락과 복구, 상품 식별과 인용 링크를 점검한다. 모의 응답 시험은 실제 이미지 전반의 OCR 정확도를 입증하지 않는다.
- 로컬 브라우저에서 직접 입력·분석·조건 펼치기·인용 링크 표시를 확인했다. 390px 화면의 가로 넘침도 점검했다.
- 배포 전 개발 검증이다. Render 배포 후에는 실제 서비스에서 다시 확인해야 한다.

## 심사 항목과 확인 범위

| 공식 항목 | 확인한 구현과 이번 보완 | 남은 확인 범위 |
|---|---|---|
| 문제정의 및 해결능력 | 설명·조건 연결, 상품 오연결 방지, 인용 자료 바로 열기 | 배포 후 실제 주소의 연결·분석 확인 |
| AI 기술의 구현 수준 및 결과물의 완성도 | OCR 이미지 번호 검증, 부분 실패 복구, 실패 범위 표시, 회귀시험 | 실제 서버의 JPG·PNG·스캔 PDF 확인. 전 제품·전 이미지 정확도는 별도 문제 |
| 사회문제 해결 기여도 | 구매 전 조건 확인, 다섯 질문·비교·읽기 지원, 기존 6명 정보 탐색 시험 | 실제 구매 의사결정·피해 감소 효과는 이번 시험으로 입증하지 않음 |
| AI 기술의 창의적 응용 | AI 추출·OCR, 조건·출처 검사, 공통 질문, 관리자 승인·정정의 결합 | 개별 기술의 최초성·경쟁 서비스 대비 우위를 새로 입증한 것은 아님 |

## 보존

저장 카드·승인 기록·기존 연구 수치·고정 검증자료 65개·기존 예측을 수정하지 않는다. 영상·음성·자막·PPT와 대본 검토안도 변경하지 않는다. 이번 수정은 코드와 개발 검증에 한한다.
