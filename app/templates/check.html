주소로 확인하기 어려울 때

판매처가 서버 접근을 제한하더라도, PC에서 상품 페이지가 정상적으로 열린다면 현재 보이는 상품 설명과 상세 이미지 주소를 보내 분석할 수 있습니다. 이미지 주소도 접근이 제한되면 해당 이미지는 읽지 못할 수 있습니다.

  1. 아래 ‘AI 정보카드로 확인’ 버튼을 브라우저의 즐겨찾기 막대로 끌어다 놓습니다.
  2. 판매페이지에서 상품 상세 설명을 펼친 뒤, 등록한 즐겨찾기를 누릅니다.
  3. 새 창에서 본문 분석과 상세 이미지 문자 인식이 이어집니다.
AI 정보카드로 확인
  • 상품 설명 영역의 본문·상세 이미지 주소·페이지 주소를 보냅니다. 쿠키·로그인 토큰·입력란은 보내지 않습니다. 공개된 상품 상세페이지에서만 사용해 주세요.
  • 기존 즐겨찾기를 등록했다면 이 버튼으로 다시 등록해 주세요. 판매처의 보안 설정이나 페이지 구성에 따라 전송이 제한될 수 있습니다.
  • 확인 결과는 저장하지 않습니다. 정식 카드를 요청할 때만 주소와 제품 이름을 받습니다.
  • 휴대폰에서는 상세페이지를 캡처해서 올리는 방법이 편리합니다.

바로 확인과 정식 카드의 차이

  • 보는 자료 자동 분석은 사용자가 입력한 주소·캡처·설명 글을 대상으로 합니다. 정식 카드는 판매페이지·설명서·사양표·공공 DB 등 확보한 자료를 함께 검토합니다.
  • 판정 바로 확인은 ‘관련 문장 있음·없음’을 표시합니다. 정식 카드는 검토자가 자동 초안을 원문과 대조한 뒤 ‘작동 설명 있음·없음·추가 확인 필요’를 표시합니다.
